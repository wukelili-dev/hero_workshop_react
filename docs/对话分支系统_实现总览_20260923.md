## 一、今晚做了什么（一句话）

把 NPC「交谈」从**单句独白**升级为**可多轮选择的分支对话**，并配套落地了：42 个 NPC 的通用台词扩充、长安 4 个新 NPC（含 2 女）、以及「隐藏 NPC 通过对话菜单解锁后现身地图」的完整机制。

分三个阶段完成，全部 `tsc --noEmit` 通过。

## 二、对话系统整体架构（三层）

| 层 | 文件 | 职责 |
|---|---|---|
| **L2 通用层** | `src/data/npcEcology.ts` | 5 语气 × 状态档的通用台词池，42 个 NPC 自动共享，零手写 |
| **L3 手写层** | `src/data/dialogues.ts` | 特定 NPC 的专属话题池 + 剧情分支树 |
| **玩家方向盘层** | `src/engine/DialogueSystem.ts` | 把「NPC 抛话 → 玩家选 → NPC 回应」串起来，结算世界级效果 |

底层条件引擎是 `src/engine/NpcDialogue.ts` 的 `matches()`（纯数据条件求值），三层都复用它做显隐/跳转判断。

### 阶段 A：L2 通用层扩充 + 去重轮换

**隐藏 NPC 解锁机制（完整链路）**：
1. `NpcDefinition.hiddenFlag` 指向一个世界旗标（如 `nieyinniang_unlocked`）
2. `isNpcUnlocked()`（`NpcSystem.ts`）判断：有 `hiddenFlag` 且旗标未立 → 返回 false
3. NpcPanel 过滤隐藏 NPC，未解锁时显示虚线占位卡（❓？？？ + `unlockHint`）
4. 解锁靠**对话树**：找「神秘老者」交谈 → 分支树选择 → `effects` 落 `worldFlag: 'nieyinniang_unlocked'`
5. NpcPanel 订阅 `worldFlags`，旗标一立，占位卡立刻变成正常 NpcCard

## 四、关键机制速查

### 1. 世界旗标 vs 探索旗标

| | 世界旗标 worldFlag | 探索旗标 explorationFlag |
|---|---|---|
| 存储 | `useWorldStore.worldFlags` | `useNpcStore.explorationFlags` |
| 用途 | 剧情走向/隐藏 NPC 显隐 | 事件解锁（魏征/唐王/玄奘） |
| 设置方式 | 对话 `effects.worldFlag` 或 `world.setWorldFlag()` | `setExplorationFlag()` |

二者并存不冲突。对话树/话题的条件用 `when: { worldFlag: 'xxx' }` 或 `{ notWorldFlag: 'xxx' }`。

### 2. 变量插值（写台词必用）

`${self}` 自称、`${call}` 对玩家称呼、`${name}` 名、`${title}` 称号、`${catch}` 口头禅、`${day}` 天。由 `renderLine()` / `interpolate()` 渲染。

### 3. 效果结算入口

所有对话效果（亲密度/情绪/物品/金币/善恶/旗标/第三方关系/流言）统一走 `DialogueSystem.applyWorldEffect()`。

### 4. 存档兼容

新增字段（`recentTopics`、`worldFlags`）在 `loadEco`/`loadWorld` 里都做了旧档归一化补默认值，老存档不会崩。

## 七、接手人快速上手

1. 想给某 NPC 加闲聊 → 在 `src/data/dialogues.ts` 的 `CHAT_TOPICS[npcId]` 加一条 `ChatTopic`（`lines` + `options`）。
2. 想加剧情分支 → 在同文件 `DIALOGUE_TREES[npcId]` 加一棵 `DialogueTree`（`root` + `nodes`），用 `when` 控制触发，用 `effects.worldFlag` 落旗标驱动后续。
3. 想加隐藏 NPC → 在 `npcs.ts` 加 NPC 并设 `hiddenFlag` + `unlockHint`，再在某 NPC 的对话树里加解锁选项落对应旗标即可。
4. 想扩通用台词 → 只改 `npcEcology.ts` 的 `TONE_GREET`/`CHANNEL_LINES`/`GENERIC_RULES`，全员受益。
